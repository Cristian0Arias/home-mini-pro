# Home Mini Pro

App web (PWA) para darle nuevas funciones a un Google Home / Nest Mini mediante Google Cast:

- Radios en vivo de todo el mundo (directorio abierto Radio Browser)
- Enviar cualquier enlace de audio directo (mp3, m4a, aac, ogg, flac, streams)
- Cola de reproducción con avance automático
- Controles remotos: reproducir/pausa, anterior/siguiente, avance, volumen y silencio

Funciona en Google Chrome o Microsoft Edge (PC y Android) conectados a la misma red Wi-Fi que el parlante.
Safari en iPhone no es compatible con Cast web.

Para probarla en local en Windows: `powershell -ExecutionPolicy Bypass -File .\servidor.ps1` y abre http://localhost:8080
